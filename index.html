QEC-1 / Buildable classical demonstrator

A physical machine for coherent computation.

QEC-1 is a 600 × 420 mm tabletop computer built around a Raspberry Pi 5, a Pico 2 panel controller, 24 keys, and 56 addressable lights. It executes Hebrew-letter programs deterministically, shows state moving through the machine, and preserves a complete trace of every run.

What the machine actually does

Input becomes visible state.

The Tree supplies the responsibility map. Conventional, available electronics do the work. A key press becomes a versioned event; the host advances the canonical runtime; the panel displays the exact state that the trace records.

01 / INPUT

Press a Hebrew key

Twenty-two letter keys enter instructions. STEP and RUN control execution. The 6 × 4 diode matrix prevents ambiguous key events.

02 / PANEL CONTROL

Pico 2 reports the event

The panel controller debounces the switch and sends a versioned JSON Lines message to the host over USB serial.

03 / COMPUTE

Pi 5 advances the runtime

The host validates the program, applies the deterministic letter operation, updates 23 registers, and records the trace.

04 / MANIFEST

The panel shows the result

Node, path, and register lights render the same canonical state shown on screen and preserved by checksum.

Engineering boundary

A real machine, honestly classified.

QEC-1 is a buildable classical control-and-display computer. It contains no qubits and claims no superposition, entanglement, quantum error correction, or quantum speedup. Two external, fused 5 V supplies power separate host and panel domains; there is no mains voltage inside the enclosure.

Meaning boundary

The Tree guides responsibilities.

The sefirot are not claimed as electronic forces. Their relationships give the machine a disciplined way to separate intention, generation, structure, permission, restraint, coordination, persistence, representation, integration, observation, and output.

IvritCode → OpenQASM 3

Hebrew opcodes become modern quantum instructions.

IvritCode now has a versioned OpenQASM 3 projection target. Each of the twenty-two Hebrew instructions emits an operation from the standard gate library, receives explicit qubit addresses, and ends in measurement. The output is portable quantum source code, ready for validation or later transpilation by a compatible toolchain.

Live translation boundary

Write in IvritCode. Inspect the circuit.

This translator emits code only. It does not send a job to a simulator or quantum processor, and the letter-to-gate profile is an explicit QEC project convention rather than a claim about the inherent meaning of the Hebrew letters.

    What changed / 2024—2026
    
              
    The fault-tolerant frontier
    
            
    
            
    
              Recent progress converges on one lesson: useful quantum
              computation is a systems problem. Better physical devices matter,
              but so do codes, connectivity, real-time decoding, logical
              operations, and hybrid control.
            
    
          
    
          
    
            
    
              01 / BELOW THRESHOLD
              
    Errors fall as codes grow
    
              
    
                Google’s Willow experiments showed exponential logical-error
                suppression as surface-code distance increased—an essential
                fault-tolerance milestone, not yet a general-purpose machine.
              
    
              GOOGLE RESEARCH ↗
            
    
            
    
              02 / DYNAMIC CODES
              
    Architectures become adaptable
    
              
    
                Dynamic surface-code circuits demonstrated error correction with
                fewer couplers and alternative gates, allowing architectures to
                route around defective components.
              
    
              GOOGLE RESEARCH ↗
            
    
            
    
              03 / NEUTRAL ATOMS
              
    Logical systems scale differently
    
              
    
                A 2025 experiment used up to 448 neutral atoms to combine
                below-threshold correction, logical operations, qubit reuse, and
                universal gate ingredients.
              
    
              NATURE ↗
            
    
            
    
              04 / REAL-TIME CONTROL
              
    Decoding enters the loop
    
              
    
                IBM reported sub-480-nanosecond decoding on FPGA hardware while

    Design doctrine
    
              
    What the frontier teaches the Tree
    
            
    
            
    
              The model borrows structural lessons—not scientific authority—from
              quantum computing’s most important advances.
            
    
          
    
          
    
            
    
              I / ENCODE
              
    Protect meaning through relationship
    
              
    
                A logical qubit is distributed across physical qubits. In this
                model, meaning likewise lives in patterns among registers and
                paths, never in an isolated symbol.
              
    
            
    
            
    
              II / CORRECT
              
    Constraint makes scale possible
    
              
    
                Error correction succeeds only below a threshold. Gevurah
                represents the necessary boundaries—validation, permissions, and
                correction—that let expansion remain coherent.
              
    
            
    
            
    
              III / OBSERVE
              
    Measurement is an interface
    
              
    
                Quantum measurement produces classical information. Da’at is
                modeled as that boundary: an event layer that selects and
                records a readable state without claiming literal wave-function
                collapse.
              
    
            
    
            
    
              IV / DECODE
              
    Interpretation belongs in the loop
    
              
    
                Fast decoders turn noisy syndrome data into corrective action.
                Hod and Yesod render, route, and reconcile trace information
                before it becomes output.
              
    
            
    
            
    
              V / CO-DESIGN
              
    No layer succeeds alone
    
              
    
                Hardware, codes, connectivity, controls, and compilers must
                evolve together. Tiferet is the coordinating service, not a
                decorative center.
              
    
            
    
            
    
              VI / VERIFY
              
    Poetry must remain traceable
    
              
    
                Every symbolic reading should point back to computed state, a
                path event, or an explicit project convention. Unsupported marks
                remain visible, never silently meaningful.
              
    
            
    
          
    
        
    
      
    

      
    
        
    Quantum Etz Chaim / IvritOS / IvritCode
    
        
    One computation, two complementary views
    
        
    
          
    
            01 / IVRITCODE
            
    The executable foundation
    
            
    
              IvritCode is the language and deterministic 23-register engine.
              Hebrew letters are instructions; the engine owns parsing, state
              transitions, seeds, and the complete execution trace.
            
    
          
    
          
    
            02 / QUANTUM ETZ CHAIM
            
    The architectural view
    
            
    
              Quantum Etz Chaim is the Tree-based systems atlas and workbench.
              It maps the same run through services, paths, gates, Da’at
              observation, and Malchut manifestation. It does not maintain a
              separate register engine.
            
    
          
    
          
    
            03 / IVRITOS
            
    The organizing layer
    
            
    
              IvritOS names the orchestration model: intent enters at Keter,
              validation and policy shape the run, Yesod records replayable
              state, and Malchut presents an observed result.
            
    
          
    
          
    
            04 / EXCHANGE
            
    The reproducible handoff
    
            
    
              IvritCode sends source, initial and final state, engine and path
              versions, seed, complete trace hash, and manifestation version.
              Quantum Etz Chaim validates that envelope before visualizing it.
            
    
          
    
        
    
        
    
          “The Tree is the architecture. IvritOS is the order
          within it. IvritCode is the language that moves through it.”
        
    
        
    
          The working loop is simple: write Hebrew source in IvritCode, execute
          it once in the canonical engine, carry the versioned trace across the
          exchange contract, and inspect that same result here. Edit in
          IvritCode returns the original source, so exploration can continue
          without losing provenance. The framework is experimental, the
          coherence layer is simulated, and the invitation is to study—not to
          mistake correspondence for proof.
